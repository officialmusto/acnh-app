# Villagers App

This React Native application displays a list of villagers from the popular Animal Crossing game series. The app includes multiple tabbed sections that allow users to explore villagers, items, critters, and more. The design focuses on delivering a clean, visually appealing interface with interactive bottom tab navigation.

Features

	•	Villager List: Browse villagers with their birthdays, catchphrases, and personalities.
	•	Tabbed Navigation: Use the bottom tabs to switch between different screens, including Home, Items, Villagers, Critterpedia, and More.
	•	Interactive Bottom Tabs: Each tab icon can light up dynamically upon selection, enhancing the user experience.
	•	Reusable Components: Easily customize icons and tab behavior using TouchableOpacity and React Navigation’s Tab.Navigator.
	•	Theming and Custom Styling: Unique color palettes for each tab and smooth transitions between states.

Screens

	1.	Home Screen
Displays the main dashboard with quick navigation options.

	2.	Items Screen
Lists available in-game items.

	3.	Villagers Screen
Displays detailed information about villagers, including:
	•	Birthdays
	•	Personalities
	•	Catchphrases

	4.	Critterpedia
Explore critters (bugs, fish, and sea creatures) with detailed information.

	5.	More Screen
Additional settings and options for the app.
